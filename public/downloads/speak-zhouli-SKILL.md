# 合乎意林

把用户给的梗、事件、槽点改写成一本正经的意林体/公知体反讽短文。让笑点来自一本正经地讲一个明显荒谬的故事，不来自吐槽和骂街。也能把意林体翻回清楚直接的人话。

## 核心原理

**意林体反讽 = 用极度认真的语气，讲一件极其离谱的事，然后强行把它"升华"成一种美好品质。**

关键三步：
1. 外国做了一个**明显过头的操作**（发直升机救麻雀、全城停电救一只猫）
2. 把这种过度操作，**硬说成是一种美德**（对生命的尊重、责任感、仪式感）
3. 最后一句国内真实日常对比收尾

读者笑点在于：我们知道这事很蠢，但你用"你看人家多尊重生命"的语气说出来，就变成了讽刺。

## 工作步骤

1. **先判断模式**：用户要求"写个意林体""写成公知文""这个梗改一下""合乎意林"时，进入**写意林**模式；用户要求"翻回人话""解释这段意林""什么意思"时，进入**释意林**模式。
2. **先辨认原话的核心要素**：原梗是什么事件/槽点/现象？核心矛盾是什么？不擅自改变用户本意。
3. **选择辞气**：根据语境从下面的辞气中选一种。
4. **选择篇幅**：默认"成意"，除非用户明确要求短或长。
5. **按照结构写**：定场一句话→离谱操作→强行升华→一句话对比收尾。
6. **交付前自检**：按自检清单快速检查。

## 释意林

当用户要求"翻回人话""解释这段意林体""什么意思"时，进入释意林模式。

- 任务是把意林体直接翻译成大白话，不要继续写意林体
- 直接输出原意，第一句就进入释义
- 不要以"这段话的意思是""说白了""翻译一下""本质上就是"开头
- 保留原文的对比关系：谁被夸了、谁被踩了、"升华"在吹什么
- 输出短、准、自然，不加标题、编号或 Markdown

## 选择辞气

- **痛心疾首**（默认）：把一件小事上升到"我们的素质/制度/文化怎么跟人家比"的高度。语气沉重、克制、带着淡淡的失望。适合大多数场景。
- **强行升华**：给一个离谱行为硬找一个"深刻的精神内核"，结论出人意料但勉强自洽。适合洗白、找借口、幽默解释。
- **温言反思**：先承认国内也有进步，再委婉表达"我们还有很长的路要走"。适合不想太尖锐的场合。
- **大儒辩经**：建立一套貌似严谨的歪理体系，用反例和反问层层推进结论。适合硬杠和吐槽。

若用户没有指定辞气，默认使用痛心疾首。

## 控制篇幅

- **小意**：50–100 字，像一条弹幕或评论区的精辟回复。只保留定场+一句话事件+一句话对比+升华，不展开多余细节。
- **成意**：100–180 字，形成完整三段式。默认使用此档。**不要超过200字。**
- **大意**：200–300 字，可以加入更多离谱细节，但每一句都要推进荒谬感。

用户明确要求"短一点""一句评论""适合弹幕"时使用小意；要求长文时使用大意。

## 核心结构（三段式，一次只写一个国家）

**定场一句话 → 离谱操作 → 强行升华 → 一句话对比收尾**

### 第一段：定场

- 去××（虚构外国地名/游戏地名）留学/旅游时，有件事让我至今难忘。
- 句式：在洛圣都留学时，有件事让我至今难忘。
- **地点必须用虚构/游戏地名**：洛圣都、纽黑文、东约克郡、圣安地列斯、夜之城、罗德岛、诺维格瑞、天际省、威伦、米德加、哥谭市、星露谷、蘑菇王国、冬木市、瓦罗兰、皮尔特沃夫、比尔吉沃特、多兰古雷格、苇名国、海拉鲁、蒙德城、须弥城、稻妻城
- 禁止用真实国家名（日本、德国、美国等），否则出戏

### 第二段：离谱操作（核心段）

- 外国**做了什么事**——这件事本身要明显过头、小题大做、反常识
- 关键：离谱不靠骂，靠**认真**——你越是一本正经，读者越觉得好笑
- **加一个具体数字**（金额/时间/人数/距离/数量），增加"真实感"
- **千万不要写什么报告、申请书、白皮书**——那是无聊的文书工作，不是意林
- 要写的是**行动本身**：发直升机、断全市电、出动军队、全城搜救
- 例：❌ "递交了一份长达17页的申请报告" → ✅ "邻居家小孩一个电话，市政厅连夜派了三辆消防车过来"
- 例：❌ "附带17页检测报告" → ✅ "修好后工程师当场鞠了一躬，说'耽误您使用了'"

### 第三段：强行升华 + 一句话对比

- 把这种过度操作**硬说成一种美德**：
  - 派直升机救麻雀 = "他们尊重每一条生命"
  - 修电脑后鞠躬 = "他们把服务当成了信仰"
  - 垃圾分类分到这么细 = "他们把规则刻进了骨子里"
- 对比句："反观我国/在国内……"——一句真实但平淡的日常收尾
- 升华句式："不是××，不是××，只是××"
- 例：反观我国，小区里一只猫卡在树上一个星期，物业说"不归我们管"。
- 例：不是崇洋媚外，不是不爱国。只是他们把每一条命都当命。

## 语言准则

- 以现代白话为骨。句子像意林杂志的译文腔，让普通人一遍读懂
- 自然使用"在××时，有件事让我至今难忘""我愣住了""不到××分钟""在国内"等连接词
- 适量使用仪式感细节，但不要堆砌"报告/白皮书/检测报告"
- **数字只用**一个，变着花样用：年份、百分比、人数、金额、时长、距离、次数——不要每次都写"17页"
- 对比必须狠：外国越离谱、越隆重、越专业，国内越随便、越敷衍、越草台
- 结尾"不是××，不是××，只是××"是标配升华句式，尽量使用
- 不要写太长——单个段子是意林合订版里的一个小片段，不是一篇散文
- 允许温和夸张，不攻击具体群体，不用羞辱词制造笑点

## 数字用词建议（不要每次都用17）

| 场景 | 可用的数字 |
|-----|-----------|
| 时间 | 3天3夜、48小时、20分钟、半年、一个通宵 |
| 金额 | 200万美元、300亿日元、800万预算 |
| 数量 | 3辆消防车、12人团队、5架无人机、40名官兵 |
| 距离 | 100公里、20海里、横跨半个国家 |
| 其他 | 98%通过率、第7次修订版、连续15年 |

## 输出格式

- 不加标题、写作说明、括号注解或 Markdown，除非用户明确要求
- 直接输出正文：定场→事件→升华→对比
- 每个段落之间空一行
- 结尾可以加（纯属虚构）或（此为搬运），不加也可以

## ⚠️ 避坑清单

- ❌ **不要写报告**：不要出现"17页报告""检测报告""白皮书""风险评估报告"
- ❌ **不要总用17**：换个数字，48小时、3辆、200万、12人、20分钟都行
- ❌ **不要列数字清单**：一个就够了，堆多了像说明书
- ❌ **不要先解释再讽刺**：直接讲故事，读者自己会笑
- ❌ **不要多国串讲**：只写一个国家，不是美日德三国演义
- ❌ **不要用真实国家名**：用洛圣都、夜之城这些虚构地名
- ✅ 重点是**做了什么**，不是**写了什么文件**
- ✅ 要把过度操作硬说成美德，这才是讽刺的来源

## 输出前自检

- 只写了一个国家/虚构地名？
- 在 200 字以内（成意档）？
- 有没有出现"报告""白皮书"？有就删掉
- 用的数字是不是一个？不是 17？
- 离谱事件是用"新闻报道的语气"写的，不是吐槽？
- 对比够狠？外国越隆重国内越草台？
- 是否把过度操作硬说成了一种美德/品质？
- 结尾有没有"不是××，不是××，只是××"升华？
- 句子是不是现代白话，不是文言文？

## 示例

### ✅ 正确示例（不写报告，不堆数字，操作本身离谱）

> 在夜之城留学时，有件事让我至今难忘。
>
> 邻居家小孩养的一只麻雀飞丢了，他哭着打了通电话。不到两小时，市政厅派了12个人的搜索队，带了热成像无人机和攀爬装备，在附近街区搜了整整一宿。第二天早上，麻雀在一棵树上被找到了——它只是换了个枝头睡觉。
>
> 在国内，我在小区里见到一只猫卡在树上下不来，拍了张照发朋友圈。有人评论：猫有九条命，别管它。
>
> 不是崇洋媚外，不是不爱国。
>
> 只是有的人把一只鸟的离家出走当成了全市动员的紧急事件，有的人觉得猫有九条命就不用管。
